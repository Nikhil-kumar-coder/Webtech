# WebTech Atlas — Study Hub

A redesigned, responsive study companion for CS35302 Web Technology (B.Tech CSE, Semester 5).

## Features
- Five unit-wise modules covering the subject outline
- Topic summaries and practical examples
- Bloom's taxonomy exam guide (L1–L6)
- Interactive study panels
- Light/dark theme toggle
- Responsive desktop and mobile layout
- Static-site architecture compatible with GitHub Pages

## Technologies
HTML5, CSS3 and vanilla JavaScript. No build step or backend required.

## Run locally
Open index.html in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Deploy to GitHub Pages
1. Open **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
4. Wait for the Pages deployment to finish.
